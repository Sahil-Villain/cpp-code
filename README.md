## 📋 Overview

A **comprehensive collection of C++ implementations** covering all major algorithms and data structures. This repository serves as a reference guide and practice resource for mastering DSA for interviews and competitive programming.

---

|:---:|:---|

## 💡 Key Algorithms with Complexity

| Algorithm | Time Complexity | Space Complexity |
|:---|:---:|:---:|
| Merge Sort | O(n log n) | O(n) |
| Quick Sort | O(n log n) avg | O(log n) |
| Dijkstra's | O((V+E) log V) | O(V) |
| BFS / DFS | O(V + E) | O(V) |
| Binary Search | O(log n) | O(1) |
| Segment Tree | O(log n) query | O(n) |
| Dynamic Programming (typical) | O(n²) | O(n) |

## 🚀 How to Run

```bash

git clone https://github.com/Sahil-K-Y/Cpp-Algorithms.git
cd Cpp-Algorithms

# Compile any file
g++ -O2 -o output filename.cpp

g++ -std=c++17 -O2 -o output filename.cpp
```
