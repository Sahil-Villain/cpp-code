# C++ Algorithms & Data Structures

![C++](https://img.shields.io/badge/Language-C++-00599C?style=for-the-badge&logo=c%2B%2B&logoColor=white)

Welcome to my C++ repository! This project is a comprehensive collection of various algorithms and data structures implemented in C++, organized for easy navigation and learning.

---

## 📂 Repository Structure

The repository is divided into two main categories: **Algorithms** and **Data Structures**.

### 🟢 Algorithms
Detailed implementations of core algorithmic techniques:
- **Backtracking**: N-Queens, Sudoku Solver, Rat in a Maze, etc.
- **Math**: Armstrong Number, Sieve of Eratosthenes, Euclidean Algorithm, etc.
- **Recursion**: Tower of Hanoi, Combinations, Permutations, etc.
- **Searching**: Binary Search, Matrix Search, etc.
- **Sorting**: Merge Sort, Quick Sort, Count Inversions, etc.

### 🔵 Data Structures
Efficient implementations of fundamental data structures:
- **Arrays & Strings**: Kadane's Algorithm, Spiral Matrix, Two Sum, etc.
- **Graphs**: BFS, DFS, Dijkstra, Kahn's Algorithm, etc.
- **Heaps**: Heap operations and management.
- **Linked Lists**: Circular, Doubly, and Singly Linked List operations.
- **Trees**: BST operations, Binary Tree traversals, etc.

## 🛠️ Getting Started

### Prerequisites
- A C++ compiler (e.g., `g++`, `clang++`, or `MSVC`).

### How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/Sahil-K-Y/Cpp.git
   ```
2. Navigate to the desired file:
   ```bash
   cd algorithms/sorting
   ```
3. Compile and run:
   ```bash
   g++ merge_sort.cpp -o merge_sort
   ./merge_sort
   ```
